# LHTRALesson09

ASP.NET Core MVC - bài quản lý tài khoản lấy ý tưởng từ giao diện Create Account.

## Chức năng
- CRUD tài khoản: Create / Read / Update / Delete
- Validation bằng DataAnnotations
- Upload + preview ảnh đại diện
- Tìm kiếm theo họ tên, email, số điện thoại
- Lọc theo giới tính
- Trang chi tiết hồ sơ
- Lưu dữ liệu JSON, không cần cài SQL Server
- Giao diện responsive

## Ý tưởng mở rộng
- Đăng nhập và phân quyền Admin/User
- Hash mật khẩu bằng ASP.NET Core Identity
- Kiểm tra email/số điện thoại trùng
- Dashboard thống kê
- Phân trang
- Dark mode
- Export Excel/PDF
- Kết nối SQL Server/EF Core

## Chạy
Mở `LHTRALesson09.sln` bằng Visual Studio 2022 có .NET 10 SDK, sau đó nhấn Ctrl+F5.
